## 1. 内置函数

### 输入输出

| 函数 | 说明 |
| --- | --- |
| `输出(...)` / `print` | 打印，多个值用空格分隔，末尾换行 |
| `写(...)` / `write` | 打印但不换行 |
| `输入(提示="")` / `input` | 读一行键盘输入（返回字符串，EOF 时返回 `空`） |
| `清屏()` / `clear` | 清空终端 |
| `参数` / `argv` | 命令行参数列表 |

### 类型转换

| 函数 | 说明 |
| --- | --- |
| `字符串(x)` / `str` | 转成字符串 |
| `数字(x)` / `num` | 转成数字，转不出来返回 `空` |
| `整数(x)` / `int` | 转成整数（截断小数） |
| `浮点(x)` / `float` | 转成浮点数 |
| `布尔(x)` / `bool` | 按真假规则转换 |
| `列表(x)` / `list` | 转列表（字符串会拆成字符） |
| `字典(x)` / `dict` | 转字典 |
| `类型(x)` / `type` | 返回类型名：`数字 字符串 布尔 空值 列表 字典 函数 类 对象 模块` |

### 类型判断

`是数字(x)` `是字符串(x)` `是列表(x)` `是字典(x)` `是函数(x)` `是空(x)`

### 数学

| 函数 | 说明 |
| --- | --- |
| `绝对值(x)` / `abs` | |
| `平方根(x)` / `sqrt` | |
| `幂(a, b=2)` / `pow` | a 的 b 次方 |
| `四舍五入(x, n=0)` | n 是小数位数 |
| `上取整(x)` / `ceil`、`下取整(x)` / `floor` | |
| `最大(...)` / `min` | 多个数，或传一个列表 |
| `最小(...)` / `min` | |
| `求和(列表)` / `sum` | |

### 序列

| 函数 | 说明 |
| --- | --- |
| `长度(x)` / `len` | 列表/字符串/字典/区间的长度 |
| `范围(n)` / `range` | `[0,1,...,n-1]`；`范围(a,b)`、`范围(a,b,步长)` |
| `区间(a, b)` | 惰性区间对象（用于遍历，省内存） |
| `枚举(列表)` | `[[0, 第一个], [1, 第二个], ...]` |
| `压缩(列表1, 列表2)` / `zip` | 拉链式合并 |
| `映射(函数, 列表)` / `map` | |
| `过滤(函数, 列表)` / `filter` | |
| `归约(函数, 列表, 初值=空)` / `reduce` | |
| `排序(列表, 键函数=空)` / `sorted` | 返回**新**列表 |
| `反转(x)` / `reversed` | 字符串返回字符串，列表返回列表 |
| `切片(x, 起=空, 止=空)` | |
| `包含(容器, 值)` / `contains` | |
| `追加(列表, 值...)` / `push` | 原地修改 |
| `弹出(列表, 下标=-1)` / `pop` | |
| `去重(列表)` | 保持原有顺序 |
| `展平(列表)` | 多维列表摊平成一维 |
| `连接(列表, 分隔符="")` / `join` | |
| `分割(字符串, 分隔符)` / `split` | 省略分隔符时按空白切 |

### 字符串

`替换(s, 旧, 新)` `去空白(s)` `大写(s)` `小写(s)` `查找(s, 子串)`
`计数(x, 值)` `字符码(c)` `码转字符(n)` `补零(s, 宽度)` `居中(s, 宽度)`
`格式化("{} {}", a, b)`（也支持 `%s` 风格）

### 时间与随机

`现在()`（"2026-09-25 21:00:00"）`时间戳()` `睡眠(秒)`
`随机()`（0~1 浮点）`随机整数(a, b)`

### 文件与 JSON

| 函数 | 说明 |
| --- | --- |
| `读文件(路径)` | 找不到文件时报错 |
| `写文件(路径, 内容)` | 自动创建目录 |
| `追加文件(路径, 内容)` | |
| `文件存在(路径)` | 返回布尔 |
| `JSON解析(文本)` | JSON → 字典/列表 |
| `JSON生成(值, 缩进=2)` | 值 → 格式化 JSON 文本 |

### 其他

`断言(条件, 消息="断言失败")` `帮助(名字=空)` `退出(码=0)`
`错误(消息, 类型="错误", ...)` —— 构造一个错误对象

## 4. 自带库（用 Qiuli 写的）

### 数据结构（`导入 "数据结构" 作为 ds`）

```ql
导入 "数据结构" 作为 ds

让 栈 = ds.建栈()
栈.压入(1).压入(2)
输出(栈.栈顶(), 栈.弹出(), 栈.大小())

让 队列 = ds.建队列()
队列.入队("a").入队("b")
输出(队列.出队())                 # a

让 堆 = ds.建优先队列()           # 默认小顶堆
堆.放入(3).放入(1).放入(2)
输出(堆.取出(), 堆.取出(), 堆.取出())   # 1 2 3
# 大顶堆：ds.建优先队列((a, b) => a > b)

让 链表 = ds.建链表()
链表.尾部追加(1).尾部追加(2).头部追加(0)
输出(链表.转列表(), 链表.包含(2), 链表.删除(1))

让 树 = ds.建二叉搜索树()
遍历 v 于 [5, 3, 8, 1] { 树.插入(v) }
输出(树.中序遍历(), 树.包含(3), 树.大小())
```

## 5. 常用配方

```ql
# 读文件并按行处理
遍历 下标, 行 于 读文件("日志.txt").分割("\n") {
    输出("${下标 + 1}: ${行}")
}

# 统计词频
让 表 = {}
遍历 词 于 文本.分割(" ") { 表[词] = 表.取(词, 0) + 1 }

# 找出最大值所在的元素
让 最好的 = 归约((a, b) => a["分"] > b["分"] ? a : b, 学生列表)

# 一行写出 FizzBuzz
遍历 i 于 1..20 {
    输出(i % 15 == 0 ? "FizzBuzz" : (i % 3 == 0 ? "Fizz" : (i % 5 == 0 ? "Buzz" : i)))
}

# 把结果存成 JSON 下次接着用
如果 文件存在("存档.json") {
    让 数据 = JSON解析(读文件("存档.json"))
} 否则 {
    让 数据 = {"次数": 0}
}
数据["次数"] += 1
写文件("存档.json", JSON生成(数据))
```
