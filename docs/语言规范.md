# Qiuli 语言规范（1.0.0）

完整的语法与语义参考。想系统学习请看 `入门教程.md`。

---

## 1. 词法

### 1.1 标识符

以字母、下划线或中日韩汉字开头，后面可跟字母、数字、下划线、汉字。
区分大小写。`_`、`计数`、`name`、`用户名2` 都是合法标识符。

**保留字不能当变量名**（例如不能写 `让 从 = 1`，因为 `从` 是关键字）。

### 1.2 关键字（中英对照）

中文与英文写法完全等价，可以混用。

| 中文 | 英文 | 用途 |
| --- | --- | --- |
| 让 | let, var | 声明变量 |
| 常量 | const | 声明不可变绑定 |
| 函数 | fn, func, function | 定义函数 |
| 方法 | method | 类体中的方法（可省略） |
| 静态 | static | 静态成员（类体中） |
| 类 | class | 定义类 |
| 构造 | init | 构造方法 |
| 继承 | extends | 继承 |
| 如果 | if | 条件 |
| 又如果 / 否则如果 | elif, elseif | 否则如果 |
| 否则 | else | 否则 |
| 当 | while | 循环 |
| 遍历 | for | 遍历 |
| 于 / 在 | in | 在……之中 |
| 中断 | break | 跳出循环 |
| 继续 | continue | 进入下一轮 |
| 返回 | return | 返回值 |
| 匹配 | match | 模式匹配 |
| 情形 | case | 匹配的分支 |
| 默认 | default | 匹配的兜底 |
| 真 / 假 | true / false | 布尔字面量 |
| 空 / 空值 | nil, null, none | 空值 |
| 且 | and | 逻辑与（短路） |
| 或 | or | 逻辑或（短路） |
| 非 | not | 逻辑非 |
| 尝试 | try | 异常捕获 |
| 捕获 | catch | 捕获分支 |
| 最终 | finally | 总是执行 |
| 抛出 | throw | 抛出异常 |
| 导入 | import | 导入模块 |
| 作为 | as | 起别名 |
| 从 | from | 从模块导入 |
| 导出 | export | 导出名字 |
| 自身 | self, this | 当前对象 |
| 父 | super | 父类 |

### 1.3 字面量

```ql
42          3.14        1_000_000
0xFF        0b1010      0o17        1.5e3
"字符串"     '字符串'    """多行
                          字符串"""
真 假 空
[1, 2, 3]   {"键": "值"}    []    {}
1..10       1..<10              # 区间（闭 / 半开）
```

转义序列：`\n \t \r \0 \\ \" \' \$ \uXXXX`

### 1.4 注释

```ql
# 单行注释（// 是整除运算符，不是注释）
/* 块注释
   可跨多行 */
```

### 1.5 语句分隔

- 一行一条语句，换行即结束
- 一行写多条语句用 `;`：`让 a = 1; 让 b = 2`
- 同一行紧挨着写的语句会自动补分号：`如果 x { 输出(1) 输出(2) }`
- 表达式太长时，行尾是运算符或逗号会自动续行；括号内的换行任意

## 2. 变量与作用域

```ql
让 x = 1          # 可变
常量 PI = 3.14    # 不可变，重新赋值会报错
让 a = 1, b = 2   # 一次声明多个
```

- **块级作用域**：`{}`、函数体、循环体都是独立作用域
- 内层可以读外层，外层读不到内层
- 函数会捕获定义时的环境（闭包）
- 变量与内置函数同名时，变量优先（会遮蔽内置函数）

## 3. 运算符与优先级

从低到高：

| 级别 | 运算符 | 结合性 |
| --- | --- | --- |
| 1 | `= += -= *= /= %= **= //=` | 右 |
| 2 | `=> `（lambda） | 右 |
| 3 | `? :`（三元） | 右 |
| 4 | `或` `\|\|` | 左 |
| 5 | `且` `&&` | 左 |
| 6 | `== != < <= > >=` | 左 |
| 7 | `..` `..<`（区间） | 左 |
| 8 | `\|>`（管道） | 左 |
| 9 | `+ -` | 左 |
| 10 | `* / // %` | 左 |
| 11 | `非 ! - + ~`（一元） | 右 |
| 12 | `**` | 右 |
| 13 | `()` `[]` `.` `?.`（调用/下标/成员） | 左 |

说明：

- `//` 是整除，`%` 是取余，`**` 是幂（右结合：`2**3**2 == 512`）
- `/` 在两个整数能整除时返回整数，否则返回浮点数
- `??` 空值合并：`a ?? 默认值`
- `?.` 安全访问：`用户?.名字`（左边是 `空` 时整体得 `空`）
- `|>` 把左边作为**最后一个实参**传给右边

### 3.1 真假

只有 `空` 和 `假` 是假，其它（含 `0`、`""`、`[]`）都是真。

### 3.2 相等

`==` 是深度比较：列表与字典递归比较内容。
`1 == 1.0` 为真，但 `真 == 1` 为假（布尔与数字不相等）。

## 4. 控制流

```ql
如果 条件 { } 又如果 条件 { } 否则 { }
当 条件 { }
遍历 元素 于 可迭代对象 { }
遍历 下标, 元素 于 列表 { }       # 列表给出下标与元素
遍历 键, 值 于 字典 { }           # 字典给出键与值
匹配 值 { 情形 模式 { } 默认 { } }
中断 / 继续
```

可迭代对象：列表、字符串、字典（键）、区间。

`匹配` 的模式可以是字面量（`情形 1`）、绑定变量（`情形 其他`，会绑定为变量）。

## 5. 函数

```ql
函数 名字(参数1, 参数2=默认值, *可变参数) {
    返回 值
}
函数 名字(x) => 表达式          # 单表达式形式
让 f = (x, y) => x + y           # lambda
让 g = x => { 让 t = x * 2; 返回 t }
```

- 默认参数、命名参数（`f(y=2)`）、可变参数都支持
- 没有 `返回` 时返回 `空`
- 函数是值，可以传进别的函数、放进列表、作为返回值
- 递归上限 800 层（超过会报「递归过深」）

## 6. 类

```ql
类 类名 继承 父类 {
    让 类字段 = 值            # 定义时求值，实例化时复制到实例

    构造(参数) {              # 构造方法
        自身.字段 = 参数
    }

    方法名(参数) { 返回 ... }  # 方法（「函数」关键字可省略）
    属性() => 表达式           # 单表达式方法

    __字符串__() => "..."      # 特殊方法
}
```

- `自身` 指向当前对象，`父` 调用父类（`父.init(...)`、`父.方法名(...)`）
- 类字段在**类定义时求值一次**，实例化时把值复制到每个实例
  （如果字段是可变对象，各实例会共享它，需要各自独立的就在 `构造` 里赋值）
- 类本身也可以有静态成员（通过 `静态` 声明）

### 6.1 特殊方法

| 方法 | 触发时机 |
| --- | --- |
| `__字符串__` | 被 `字符串()` 或拼接时 |
| `__加__` `__减__` `__乘__` `__除__` `__取余__` `__幂__` | 对应算术运算 |
| `__等于__` `__小于__` `__小于等于__` `__大于__` `__大于等于__` | 对应比较 |
| `__负__` | 一元负号 |
| `__下标__` | `对象[键]` |
| `__调用__` | `对象(...)` |
| `__迭代__` | 被 `遍历` 时 |

运算符重载只要左边是对象就会触发（右边可以是任意值）。

## 7. 异常

```ql
尝试 {
    抛出 错误("消息", 类型="参数错误")
} 捕获 参数错误 as e {
    输出(e.消息, e.类型)
} 捕获 e {
    输出("其它：", e)
} 最终 {
    输出("一定执行")
}
```

- `错误(消息, 类型="错误", 其他数据...)` 构造错误对象
- `捕获` 可以不写类型（捕获一切）、写类型名（只捕这一类）
- 类型错误、下标越界、文件权限等**内置与系统错误也能捕获**
- `捕获` 不会吞掉 `返回`、`中断`、`继续`
- `断言(条件, "消息")` 是最常用的调试手段

## 8. 模块

```ql
导入 "数学" 作为 m
导入 数学                          # 也可以不加引号
从 "随机" 导入 整数, 选择
导入 "./我的模块" 作为 mine         # .ql 文件用路径
```

搜索顺序：脚本所在目录 → 同级 `stdlib/` → 项目自带 `stdlib/`。

模块文件里：

```ql
导出 函数1, 变量2        # 只导出指定的名字
```

不写 `导出` 时，顶层的 `让`、`函数`、`类` 全部导出。
模块只加载一次（有缓存），循环导入不会死循环。

## 9. 内置类型的方法

列表、字符串、字典都有一批方法，既能 `值.方法()` 也能用同名内置函数：

```ql
[1,2].追加(3)      "abc".大写()      字典.键
```

完整列表见 **`标准库.md`**。

## 10. 值与引用

- 数字、字符串、布尔、空是**值语义**（传参时拷贝）
- 列表、字典、对象是**引用语义**（传进去的是同一个东西）

```ql
函数 改(x) { x[0] = 99 }
让 a = [1]
改(a)
输出(a[0])      # 99
```

## 11. 错误信息

语法错误和运行错误都会指出文件名、行号、列号，并打印源码那一行：

```
语法错误: 语句未结束，期望换行或分号，实际得到 'let'
  ── 我的脚本.ql:2:1
2 | 让 x = 10
  | ^
```

运行错误还会给出调用栈：

```
运行错误: 下标越界：下标 5，列表长度 3
回溯（最近调用最后）:
    at 8 (处理:我的脚本.ql)
    at 15 (<匿名>:我的脚本.ql)
```

调试命令：`qiuli.py tokens 文件.ql`、`qiuli.py ast 文件.ql`。

## 12. 实现备注

- 解释器是**树遍历**式：解析成 AST 后直接执行，没有字节码
- 循环体在没有函数定义时会复用同一个作用域（性能优化），
  因此循环内定义的变量在循环结束后可能仍然可见
- 递归上限：Qiuli 层 800 层；Python 层限制设为 20000
