# Qiuli 入门教程

从「什么都不会」到「写出一个小项目」，共十二课。
每课都配有可以直接运行的代码，建议边读边敲。

> 运行方式：把代码存成 `课程.ql`，然后 `python qiuli.py 课程.ql`
> 也可以直接 `python qiuli.py` 进 REPL 一行行试。

---

## 第 1 课 输出与注释

```ql
输出("你好，Qiuli！")        # 打印一行
写("不换行")                 # 打印但不换行
输出("　接在上面")

# 这是注释
/* 这是块注释
   可以写很多行 */
```

`输出` 可以一次打印多个值，用空格分隔：

```ql
输出("1 + 1 =", 1 + 1)       # 1 + 1 = 2
```

> **注意**：Qiuli 的单行注释用 `#`。
> `//` 是「整除」运算符，不是注释。

## 第 2 课 变量与类型

```ql
让 年龄 = 18          # 可修改
常量 圆周率 = 3.14    # 不可修改（重新赋值会报错）
年龄 = 19

输出(类型(年龄))       # 数字
```

基本类型：数字、字符串、布尔（`真`/`假`）、空（`空`）、列表、字典。

```ql
让 名字 = "小明"       # 字符串
让 成年 = 真           # 布尔
让 暂无 = 空           # 空值

输出(类型(名字), 类型(成年), 类型(暂无))
```

数字写法很自由：

```ql
输出(1_000_000)   # 1000000（下划线只是分隔符）
输出(0xFF)        # 255
输出(0b1010)      # 10
输出(1.5e3)       # 1500
```

**真假判定**：只有 `空` 和 `假` 是假的，`0` 和 `""` 都是真。

```ql
如果 0 { 输出("0 在 Qiuli 里是真值") }
```

## 第 3 课 运算

```ql
输出(7 / 2)     # 3.5   除法
输出(7 // 2)    # 3     整除
输出(6 / 3)     # 2     能整除时结果是整数
输出(7 % 2)     # 1     取余
输出(2 ** 10)   # 1024  幂
```

字符串能拼接和重复，列表也能拼：

```ql
输出("你好" + "世界")     # 你好世界
输出("ab" * 3)            # ababab
输出([1, 2] + [3])        # [1, 2, 3]
输出("第" + 1)            # 第1（另一侧会自动转成字符串）
```

字符串插值——在引号里直接写 `${表达式}`：

```ql
让 名字 = "小红"
让 分数 = 95
输出("${名字} 考了 ${分数} 分，比及格线高 ${分数 - 60} 分")
```

## 第 4 课 判断

```ql
让 分数 = 85

如果 分数 >= 90 {
    输出("优")
} 又如果 分数 >= 60 {
    输出("及格")
} 否则 {
    输出("待努力")
}
```

简短的判断可以用三元表达式：

```ql
让 奇偶 = 分数 % 2 == 0 ? "偶数" : "奇数"
```

多分支还可以用 `匹配`：

```ql
匹配 分数 {
    情形 100 { 输出("满分！") }
    情形 0   { 输出("零分……") }
    情形 其他 { 输出("得了 ${其他} 分") }   # 「其他」会绑定成变量
}
```

## 第 5 课 循环

```ql
# 遍历列表
遍历 水果 于 ["苹果", "香蕉", "橙子"] {
    输出("我喜欢", 水果)
}

# 带下标
遍历 下标, 水果 于 ["苹果", "香蕉"] {
    输出("第 ${下标 + 1} 个：${水果}")
}

# 遍历字典的键和值
遍历 科目, 分数 于 {"语文": 88, "数学": 95} {
    输出("${科目}：${分数}")
}

# 范围：0,1,2,3,4
遍历 i 于 范围(5) { 写(i, " ") }
输出()

# 区间：1..5 是 1,2,3,4,5（闭区间）
遍历 i 于 1..5 { 写(i, " ") }
输出()

# 当……的时候（while）
让 n = 0
当 n < 3 {
    输出("n =", n)
    n += 1
}

# 中断 / 继续
遍历 i 于 范围(10) {
    如果 i % 2 == 0 { 继续 }   # 跳过偶数
    如果 i > 6 { 中断 }        # 到 7 就停
    写(i, " ")
}
```

## 第 6 课 函数

```ql
函数 加(a, b) {
    返回 a + b
}
输出(加(3, 4))

# 只有一行时可以写成箭头形式
函数 平方(x) => x * x

# 默认参数
函数 问候(谁="朋友", 后缀="！") => "你好${谁}${后缀}"
输出(问候())              # 你好朋友！
输出(问候("小明"))        # 你好小明！

# 命名参数（顺序可以打乱）
函数 建点(x=0, y=0) => [x, y]
输出(建点(y=5))           # [0, 5]

# 可变参数：参数前面加 *
函数 加总(*数字) {
    让 s = 0
    遍历 n 于 数字 { s += n }
    返回 s
}
输出(加总(1, 2, 3, 4))    # 10
```

### 匿名函数与闭包

```ql
让 翻倍 = x => x * 2
输出(翻倍(21))            # 42

# 闭包：函数会记住它被创建时的环境
函数 造计数器() {
    让 n = 0
    返回 () => { n += 1; 返回 n }
}
让 c = 造计数器()
输出(c(), c(), c())       # 1 2 3
```

### 管道 `|>`

把左边的值喂给右边的函数，可以串成一串：

```ql
让 结果 = 范围(1, 11)
          |> 过滤(x => x % 2 == 0)
          |> 映射(x => x * x)
          |> 求和()
输出(结果)                 # 220
```

> 管道是把左边的值作为**最后一个**实参传进去的，
> 这样才符合「映射(函数, 数据)」的中文语序。

## 第 7 课 列表与字典

```ql
让 a = [3, 1, 4, 1, 5]
输出(a.长度)          # 5
输出(a[0], a[-1])     # 3  5（负数从末尾数）
输出(a[1:3])          # [1, 4]（切片）
a.追加(9)
输出(a.弹出())        # 9
输出(a.包含(4))       # 真
输出(排序(a))         # [1, 1, 3, 4, 5]（返回新列表）
```

常用的高阶函数：

```ql
让 数 = [1, 2, 3, 4, 5]
输出(映射(x => x * 2, 数))            # [2, 4, 6, 8, 10]
输出(过滤(x => x > 2, 数))            # [3, 4, 5]
输出(归约((x, y) => x + y, 数))       # 15
输出(求和(数), 最大(数), 最小(数))     # 15 5 1
数.每个(x => 写(x, " "))              # 逐个做事
```

字典：

```ql
让 成绩 = {"语文": 88, "数学": 95}
成绩["英语"] = 91
输出(成绩.键, 成绩.值)
输出(成绩.包含("物理"))       # 假
输出(成绩.取("物理", 0))      # 0（取不到时用默认值）
```

字符串也有类似的下标、切片和一堆方法：

```ql
让 s = "Qiuli"
输出(s[0], s[0:3], s.长度)
输出(s.大写(), s.小写(), s.反转())
输出("a,b,c".分割(","))       # ["a", "b", "c"]
输出("  x  ".去空白())        # "x"
```

## 第 8 课 类与对象

```ql
类 动物 {
    构造(名字) {
        自身.名字 = 名字
    }
    介绍() => "我是${自身.名字}"
    发声() => "……"
}

类 狗 继承 动物 {
    构造(名字) {
        父.init(名字)          # 调用父类的构造
    }
    发声() => "汪汪"
    __字符串__() => "🐶${自身.名字}"    # 定义转成字符串的样子
}

让 d = 狗("旺财")
输出(d.介绍())        # 我是旺财（继承自父类）
输出(d.发声())        # 汪汪
输出(字符串(d))       # 🐶旺财
```

### 运算符重载

给类加上 `__加__`、`__等于__` 这样的方法，对象就能参与运算：

```ql
类 向量 {
    构造(x, y) { 自身.x = x  自身.y = y }
    __加__(另一个) => 向量(自身.x + 另一个.x, 自身.y + 另一个.y)
    __字符串__() => "(${自身.x}, ${自身.y})"
}
输出(字符串(向量(1, 2) + 向量(3, 4)))   # (4, 6)
```

可重载的运算：`__加__ __减__ __乘__ __除__ __取余__ __幂__
__等于__ __小于__ __小于等于__ __大于__ __大于等于__ __负__ __字符串__`。

## 第 9 课 异常

```ql
函数 除(a, b) {
    如果 b == 0 { 抛出 错误("除数不能为 0") }
    返回 a / b
}

尝试 {
    输出(除(10, 2))
    输出(除(1, 0))
} 捕获 e {
    输出("出错了：", e.消息)
} 最终 {
    输出("这里一定会执行")
}
```

可以按类型分别捕获：

```ql
抛出 错误("年龄不合法", 类型="参数错误")

尝试 { ... }
捕获 参数错误 as e { 输出("参数问题：", e.消息) }
捕获 e { 输出("其它问题：", e.消息) }
```

类型错误、下标越界等内置错误，以及文件权限等系统错误，也都能被 `捕获` 到。
`断言(条件, "提示")` 是最常用的调试工具，条件不成立就抛错。

## 第 10 课 模块

内置模块直接用名字导入：

```ql
导入 "数学" 作为 m
输出(m.圆周率, m.平方根(16), m.是质数(17))

从 "随机" 导入 整数, 选择
输出(整数(1, 6))

导入 "JSON" 作为 j
输出(j.生成({"a": 1}))
```

内置模块：`数学 时间 随机 文件 JSON 系统 字符串 终端`
（英文名 `math time random fs json sys str term` 也能用）。

自己写的 `.ql` 文件也可以是模块：

```ql
# 我的工具.ql
函数 两倍(x) => x * 2
导出 两倍
```

```ql
导入 "我的工具" 作为 工具
输出(工具.两倍(21))     # 42
```

搜索顺序：脚本所在目录 → 同级的 `stdlib/` → 项目自带的 `stdlib/`。
如果模块里没有写 `导出`，那么顶层的 `让`、`函数`、`类` 都会被导出。

## 第 11 课 文件与输入输出

```ql
写文件("笔记.txt", "第一行\n第二行")
输出(读文件("笔记.txt"))
追加文件("笔记.txt", "\n第三行")

让 行们 = 读文件("笔记.txt").分割("\n")
遍历 下标, 行 于 行们 {
    输出("${下标 + 1}: ${行}")
}

让 数据 = {"姓名": "小明", "成绩": [88, 95]}
写文件("数据.json", JSON生成(数据))
让 读回 = JSON解析(读文件("数据.json"))
```

读键盘输入：

```ql
写("你叫什么？")
让 名字 = 输入()
输出("你好，${名字}")
```

`输入()` 读进来的是字符串，要算数就用 `数字(...)` 或 `整数(...)` 转一下。

## 第 12 课 综合练习：成绩单

把前面学到的串起来：

```ql
让 成绩单 = [
    {"姓名": "小明", "语文": 88, "数学": 95},
    {"姓名": "小红", "语文": 92, "数学": 89},
    {"姓名": "小刚", "语文": 76, "数学": 80}
]

# 给每个人算平均分并评级
遍历 学生 于 成绩单 {
    让 平均 = (学生["语文"] + 学生["数学"]) / 2
    学生["平均"] = 平均
    学生["等级"] = 平均 >= 90 ? "优" : (平均 >= 80 ? "良" : "加油")
}

# 按平均分排序
让 排名 = 排序(成绩单, s => -s["平均"])

输出("名次  姓名   平均   等级")
遍历 下标, 学生 于 排名 {
    输出(" ${下标 + 1}    ${学生["姓名"]}   ${学生["平均"]}   ${学生["等级"]}")
}

# 全班统计
让 平均分 = 求和(映射(s => s["平均"], 成绩单)) / 成绩单.长度
输出("\n全班平均：${平均分}")
输出("最高分：${最大(映射(s => s["平均"], 成绩单))}")
```

- 把成绩单存成 JSON，下次启动自动读回来（`examples/13_待办清单.ql` 就是这么做的）
- 加一个「按科目统计」的功能
- 写一个猜数字或井字棋小游戏（`examples/11`、`examples/12` 是参考答案）

## 常见坑

| 现象 | 原因与解决办法 |
| --- | --- |
| `语句未结束` | 一行写多条语句时用 `;` 隔开 |
| 插值里的下标报错 | `${字典['键']}` 用单引号，避免和外层的双引号打架 |
| `//` 后面的内容不见了 | `//` 是整除，注释要用 `#` |
| `空 没有成员` | 用 `?.` 安全访问：`用户?.名字` |
| 变量覆盖内置函数 | `让 整数 = 1` 之后 `整数(...)` 就失效了，换个名字 |
| 递归层数过深 | 默认上限 800 层，检查是不是少写了终止条件 |
